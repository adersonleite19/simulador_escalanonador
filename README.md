# Simulador de Escalonamento de Processos

Projeto desenvolvido em Python para simular algoritmos de escalonamento de processos em Sistemas Operacionais.

## 📋 Sobre o projeto

O projeto tem como objetivo demonstrar, de forma prática, o funcionamento dos algoritmos de escalonamento de CPU.

O simulador permite analisar informações dos processos, como tempo de chegada, duração, tempo de espera, tempo de retorno e tempo de finalização.

## ⚙️ Algoritmos implementados

- FCFS (First Come, First Served)
- Round Robin (RR)

## 🛠️ Tecnologias utilizadas

- Python
- Git
- GitHub
- GitHub Codespaces

## 📊 Informações analisadas

Para cada processo são considerados:

- PID
- Tempo de chegada
- Duração
- Tempo restante
- Tempo de finalização
- Tempo de espera
- Tempo de retorno
